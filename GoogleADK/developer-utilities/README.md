# developer-utilities

A collection of practical **Agentic AI tools** built to help developers in their day-to-day work.

This repository contains intelligent agents that can:

- Scan and fix vulnerabilities in dependencies
- Optimize and improve code quality
- Automate repetitive development tasks
- Generate reports and suggestions using powerful LLMs

## Available Agents

- **[vulnerabilities-fix-agent](./vulnerabilities-fix-agent)**  
  Scans Go (`go.mod`) projects for vulnerable dependencies, generates reports, and safely upgrades them.

*(More agents will be added soon)*

## Purpose

Developers can run these agents locally to:
- Improve security of their projects
- Reduce manual effort in maintenance tasks
- Get intelligent suggestions powered by Google Gemini
- Work more efficiently with AI assistance

All agents are built using **Google's Agent Development Kit (ADK)** — clean, transparent, and controllable.

## How to Use

Each agent has its own folder with detailed instructions.  
Just clone the repo, go into the desired agent folder, and follow the `README.md` inside it.
